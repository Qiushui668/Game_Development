# PY Party Run · 彩虹冲刺

浏览器 3D 多人障碍跑酷。Vue 3 + TypeScript + Vite + Three.js + Rapier3D。

## 玩法

- 打开网站先进**昵称门**：昵称**必须自己输入**（最多 12 字，输入框没有默认值、空着点不了"进入游戏"），填好后才出现`单人游戏` / `多人游戏`两个入口；昵称会一直显示在人物头顶，联机时别人也看得到。昵称有 **1 小时时效**：有效期内刷新页面不用重填（身份条会提示还剩多少分钟），过期后自动回到昵称门重新输入。昵称门里还能挑**配色**（8 个色板 + 一个「随机」按钮）；**不挑也行**——进游戏时会随机分一个并记住，自己身上、头顶名牌、联机里别人看到的永远是同一个颜色。
- 每个角色**头顶昵称上方**还有一条**血量条 + 血量数字**（`100/100` 这种读法）：自己受伤时数字跟着掉，颜色按血量变（>60% 青绿、>30% 黄橙、其余红粉）；联机局里**别人的血条也实时显示**，能看着对手被打到多少血。
- `多人游戏` 一屏三块：**左侧创建房间**（拿 4 位房间号）、**右侧输入房间号加入**、**下方是当前在线的房间列表**（带人数 / 阶段，点一下直接进）。房间 2–8 人，房主点开始后全场同时起跑。
- **中途也能加入**：这局正在倒数 / 比赛中同样可以进房（最多 8 人，满了会提示"房间已满（8 人），等有人退出再来"），新人从起点开始跟着跑。
- **有人退出不影响别人**：谁掉线 / 主动退出都只把他自己从名单里拿掉，房间不关、比赛不停，剩下的人继续跑；房主走了自动顺延给下一个。
- 起跑倒数 3 s → 计时开跑，冲过 320 m 糖果赛道。**只要有一个人冲线，全场立刻一起进结算页**（还在跑的人也会被拉进结算，名次按服务器计时），结算面板有「返回房间」和「再来一局」两个按钮：**结算页上的人都点「再来一局」才会自动开下一局**（面板上会显示"已同意 2/3"）；点「返回房间」只把**自己**送回大厅，别人的结算页不受影响，剩下的人凑齐票也会自动开下一局（回大厅的人一起被带回赛道）。**单人局**的结算页同样是「返回房间」+「再跑一次」两个按钮（返回房间＝回首页重新选单人/多人）。
- **浏览器返回已被封**：鼠标侧键（前进/后退）、触控板左右滑、`Alt+←` / `Alt+→`、`Backspace` 和浏览器后退按钮在游戏里全部被拦下并给出提示，避免手一滑就把人从比赛里带走；真要退出请点游戏里的「退出房间」。
- **巨型拳击手套**：赛道左右墙上挂 4 只（z≈-11 / -139.4 / -183.5 / -243.6，右→左→右→左交替），沿墙**随机前后滑动**、并**随机探拳打进赛道**；平时缩回墙面（只露挂架和半只拳套），出拳时整只手臂带着拳套探进赛道（最远 6.5 m，中间始终留得下一条跑道）；被打中**先扣光 100 血（血条清零）再打飞淘汰**，飞 1 s 后回起点满血重跑。拳套只会沿墙前后走，不会左右平移；4 只的位置都挑在扫地杆/滚轴/地刺/摆锤/栏架/答题墙的空档里，俯视图上两两不重叠。
- 赛道上均布 4 面**答题空气墙**（序号 1–4）：走到墙前按 `F` 开答，答对才能穿墙；答错屏幕冻结 3 s、中央倒计时，结束后换一道新题直到答对。
- **答题墙 2 → 3 之间是浮桥段**（z −142 → −175）：这一段的方格整片挖空（掉下去就是虚空 → 回起点满血重跑），跨过去只靠 **6 块 3.6 m 见方的浮桥**。6 块前后间隔 5.5 m；**开局时第 1/3/5 块贴死最左（板心 −7.1 m，板边 −8.9 顶住护栏）、第 2/4/6 块贴死最右（板心 +7.1）**，之后 6 块同时**匀速**横移：以 3.55 m/s 一路扫到对面墙壁才**立刻反向**（三角波，单程 4 s、一来回 8 s），不是正弦那种两头慢中间快。因为起点左右相反，相邻两块永远镜像反向走，横向落差在 0…14.2 m 之间变，**只有两块在赛道中间交汇（落差 ≤ 5.7 m）的那约 1.6 s 才跳得过去**，其他时候板子贴在两边墙上 —— 这一段是掐时间的连跳（实测轨迹见 `tools/bridge_swing.png`）。**站上哪块就被哪块带着走**，踩空 / 被甩出桥面则从起点复活。为了让桥上干净，原来压在这一段的滚轴、摆锤、扫地杆、栏架分别挪到 z -205 / -109.2 / -292.5，并删掉了 -154 那一排栏架。
- **血量**：满血 100，左上角（左下）HUD 有血条；血量归零立刻从起点复活并回满 100，本局死亡次数与击杀数都会记着。
- **卡死 / 掉线不会闷着**：帧循环里任何一帧抛出异常只会丢掉这一帧并记账（`getLoopHealth()` 能看到 `errors`），不会再把 `requestAnimationFrame` 链扯断——以前一旦断掉，画面就永远停在最后一帧、别人看着不动、也打不到人。切走窗口再切回来会自动 `resync()` 重设帧基准；房间连接中途断掉（服务重启 / Wi-Fi 断）会在画面上方弹红条"连接已断开，请刷新重新进房"，不再只是"别人原地不动"。
- 题库取自 `趣味选择题100题.xlsx`（100 题），抽题会打乱选项顺序，且同一局不重复出题。
- 背景音乐 `public/audio/danzai.mp3` 循环播放（浏览器要求用户手势，首次点击画面或按键后开始）。
- 鼠标 + `WASD` 移动、`Shift` 冲刺、`Space` 跳。赛道障碍：7 根**旋转扫地杆**（转速已 ×1.6，被扫中会沿摆臂方向**甩出 7–8 m**）、3 根**滚轴**、**4 条地刺**（周期顶起，缩回时有安全窗口）、**2 座大摆锤**（钟摆式横扫赛道）；任何障碍命中统一 **−10 生命值**并被击退硬直。
- 整条赛道（20 → -322，342 m）就是一张 **6 列 × 114 行 = 684 块 3 m 方格**铺成的地面，每局开局**逐格独立随机**抽签决定身份：
  - **消失格**（默认约 4%）：踩上去先抖 0.3 s，然后整块塌下去 6 m；人跟着掉进虚空 → **回起点满血复活**（算一次"被打倒"，不额外扣血）。
  - **回弹格**（默认约 2.5%）：踩上去立刻被**往起点方向弹回约 12 m**，带 1.5 s 硬直、不扣血 —— 专门用来拖慢往前冲的速度。
  - **实心格**：普通方格，塌下去的那块会在 6–10 s 后重新长回来（碎片会先升起再落定）。
  - **看不出来**：三种身份用**同一个材质、同一张棋盘贴图、同一尺寸同一高度**（一块 InstancedMesh、不用实例色），陷阱和普通格子外观完全一致；位置也是逐格随机撒在整条赛道上，只有浮桥段（z −142 → −175，66 块）是**固定挖空**的，那一段没有方格可踩。
  - 每局重开（`restart`）或重新随机时身份全部重抽，同一位置的格子上一局和下一局不一样；只有起点平台（z 0..20）和终点前最后 7 m 保底是实心（防止出生点 / 压线那一步掉下去）。
- 攻击：鼠标**左键**单臂轻击 **−34**；**右键**双臂抬起后摇 1 s 再砸下 **−70**。判定按联机规则设计：轻击累计 3 次、重击 1 次使对方倒地眩晕 1 s（连击窗口 1.6 s）；满血下"轻击 3 下"正好打空，于是同时触发死亡回起点。
- **击杀**：把别人打到 0 血算一次击杀（障碍/自己摔死不算），击杀瞬间播 `public/audio/kill.mp3`（来自用户提供的 `1杀.mp3`），HUD 与结算榜单都显示击杀数。
- 护栏是圆角顶：跳上去会滑回赛道，站不住、也沿不了护栏跑（跳过扫地杆/栏架的漏洞已封）。
- 答题时被打倒（轻击 3 次或重击 1 次）会**中断答题**：题作废、墙不拆、眩晕 1 秒，之后回墙前重新按 `F` 换题再答；被打死同样会中断。

## 快速开始

```powershell
npm install
npm run dev      # 单人自己玩：http://localhost:5173
```

局域网联机（Vite 与服务端一起起，会打印别人该访问的地址）：

```powershell
npm run lan
```

只起房间服务（Vite 另开一个终端 `npm run dev`）：

```powershell
npm run server   # ws://0.0.0.0:8000/ws
```

同一局域网内其他人打开 `http://<你的内网IP>:5173`，在首页选多人游戏、输入房间号即可。房间 2–8 人，人数不足 2 人时房主无法开跑。

### 放到公网（没有服务器也能免费跑）

前端是纯静态、房间服务要常驻 Node + WebSocket，所以**分两处托管**：前端 Vercel / Netlify 免费，房间服务 Render 免费 Web Service（仓库根目录已带 `render.yaml`，一键 Blueprint 部署）。

关键一步：前端必须配环境变量 `VITE_ROOM_SERVER=https://你的房间服务域名`（代码会自己转成 `wss://…/ws`，不填就还是连"当前页面主机的 :8000"，局域网用法不变）。

完整步骤、免费档限制（15 分钟休眠 / 每月 750 小时）、Oracle 与 Cloudflare 备选方案见 **`docs/DEPLOY.md`**。

## 机器基线

目标显卡 NVIDIA GT 610（1 GB）。画质策略：关抗锯齿、关实时阴影、像素比固定 1、渲染分辨率封顶 1280×720。判定标准为 P99 帧时间 ≤ 50 ms。
